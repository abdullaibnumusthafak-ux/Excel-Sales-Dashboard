# ✏️ Excel Sales Analytics Dashboard (Sketch Design)

## 📌 Overview
An interactive Excel Sales Dashboard featuring a clean, hand-drawn sketch-style layout. This dashboard provides key insights into total revenue, product quantities sold, region-wise distribution, and salesman performance.

## 📈 Key Metrics & Features
* **Total Amount:** $1,782,570
* **Total Sales:** 366 units

### 🔍 Key Dashboards & Visualizations
* **Sales by Product (Amount & Quantity):** Visual comparison of revenue and volume across products (Keyboards, Monitors, Mice, Printers, Scanners, Speakers).
* **Sales by Months:** Monthly trend analysis to track seasonality and revenue spikes.
* **Sales by Region:** Regional breakdown across East, North, South, and West.
* **Product Performance:** Top 3 selling vs. Top 3 less selling products.
* **Salesman Performance:** Analysis of top-performing and low-performing sales representatives.

## 🛠️ Tools & Features Used
* **Platform:** Microsoft Excel
* **Visual Style:** Pencil / Hand-drawn Wireframe Style
* **Data Features:** Pivot Tables, Slicers (Date, Region, Item), Dynamic Charts, and Interactive Navigation Buttons
